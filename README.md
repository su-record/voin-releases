# voin

회의와 생각을 내 PC에서 받아쓰고, 다시 찾을 수 있는 기록으로 남깁니다.

[제품 소개](https://torylabs.dev/ko/voin) · [macOS 0.0.1 다운로드](https://github.com/su-record/voin-releases/releases/download/v0.0.1/voin-0.0.1.dmg)

- Apple Silicon, macOS 14.4 이상
- Windows: **Coming soon**
- 설치 파일은 Apple Developer ID 서명과 공증을 거쳤습니다.
- 마이크·화상회의 소리 받아쓰기, 화자 구분, 요약, Markdown·Obsidian 저장
- 모델 카드에서 실시간·녹음 후 받아쓰기 용도를 선택합니다.
- 받아쓰기·화자 분리는 내 PC에서 처리합니다. 외부 AI 요약을 선택하면 기록이 해당 서비스로 전송됩니다.

이 저장소는 공식 설치 파일과 서명된 업데이트를 배포합니다. 앱 메뉴의 **업데이트 확인…**에서 새 버전을 받을 수 있습니다. 녹음·받아쓰기·정리 중에는 업데이트를 설치하지 않습니다.

`latest.json`과 `.app.tar.gz.sig`는 앱의 서명 검증에 사용합니다. 직접 설치하려면 `.dmg`를 받으세요. `SHA256SUMS.txt`로 받은 파일의 해시를 확인할 수 있습니다.
